# Broken Signal Companion (необязательно)

1. Скачай артефакт `brokensignal-companion` из GitHub Actions, распакуй куда угодно.
2. Запусти `run.bat` (нужна Java 17+; та, что идёт с лаунчером, подходит, если `java` в PATH).
3. В `.minecraft/config/brokensignal-client.toml` поставь `companion = true`.
4. В игре: `/brokensignal outside test` — должно открыться окошко «проверка.txt».

Выключить: кнопка «Выключить», меню в трее или создать файл `STOP` в `%USERPROFILE%\BrokenSignalCompanion`. Без Companion мод работает полностью.
